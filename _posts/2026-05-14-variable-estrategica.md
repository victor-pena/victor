# 🧭 Del Problema Público y las Potencialidades a la Variable Estratégica

Una vez identificado el problema público y reconocidas las potencialidades del territorio, el siguiente paso es construir la **variable estratégica**.

Este es uno de los momentos más importantes del proceso de de elaboración del PDC, porque aquí el análisis deja de ser descriptivo y se comienza a identificar lo siguiente:

> qué elementos realmente mueven el sistema territorial.

---

# 🔍 ¿Qué es una variable estratégica?

Una variable estratégica no es cualquier dato o indicador.

Es un factor que:

* influye fuertemente en el funcionamiento del territorio;
* conecta problemas y potencialidades;
* puede modificar la dinámica del sistema;
* y condiciona la intervención territorial.

En términos operativos:

> Una variable estratégica es un elemento clave cuya evolución puede reorganizar el territorio.

La variable estrategica tiene dos características centrales:

* Alta influencia (afecta otras variables)
* Alta incertidumbre (su evolución futura no esta completamente determinada)

---

# ⚙️ La lógica del proceso

La variable estratégica aparece cuando se relacionan:

| Elemento             | Pregunta                                     |
| -------------------- | -------------------------------------------- |
| Problema público     | ¿Qué limita el sistema?                      |
| Potencialidad        | ¿Qué puede activar o transformar el sistema? |
| Variable estratégica | ¿Qué factor conecta ambos?                   |

---

# 🧠 Idea central

La variable estratégica no surge de una lista.

👉 Surge de una tensión territorial.

Es decir:

* existe una limitación;
* existe una capacidad potencial;
* y existe una variable que puede desbloquear o reorganizar el sistema.

---

# 📍 Ejemplo: Caso Pisco

## Problema público

> Baja articulación del nodo logístico de Pisco limita su competitividad territorial.

---

## Potencialidades

* Puerto de Pisco
* Corredor Lima–Ica
* Actividad agroexportadora
* Posible tren Lima–Ica
* Disponibilidad energética regional

---

# 🔗 Construcción de la variable estratégica

## Pregunta clave:

> ¿Qué elemento conecta el problema con las potencialidades?

---

## Variable estratégica posible:

### “Conectividad logística multimodal”

¿Por qué?

Porque:

* la baja conectividad genera el problema;
* y mejorarla permitiría activar las potencialidades del territorio.

---

# ⚠️ Error común

Los estudiantes suelen confundir:

* variable estratégica
  con
* elemento territorial.

❌ “Puerto”
❌ “Carretera”
❌ “Energía”

Eso no es suficiente.

👉 La variable debe expresar una dinámica o relación.

---

# ✅ Formulación correcta

* articulación logística;
* conectividad multimodal;
* capacidad energética;
* coordinación interinstitucional;
* integración puerto–hinterland.

# 🧭 Clave conceptual

La variable estratégica es importante porque:

* organiza el diagnóstico;
* orienta escenarios;
* prioriza inversiones;
* y define sobre qué debe intervenir el ordenamiento territorial.

En otras palabras:

> La regulación territorial efectiva no actúa sobre elementos aislados.
> Actúa sobre variables que reorganizan el sistema.
