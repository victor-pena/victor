### Caso de Estudio: Pisco como Nodo Energético y Logístico del Sur del Perú

### Objetivo

El informe tiene como finalidad integrar los resultados obtenidos durante el taller, aplicando la metodología de la **Guía CEPLAN para el Plan de Desarrollo Local Concertado (PDLC) 2024**, desde el análisis de la situación actual hasta la formulación de escenarios prospectivos.

El informe deberá demostrar la capacidad del grupo para interpretar el territorio como un sistema complejo y proponer una lectura estratégica del caso de estudio.

* Fecha

# Índice

---

# 1. Introducción

* Presentación del caso de estudio.
* Objetivos del trabajo.
* Alcance y metodología utilizada.

---

# 2. Caracterización del territorio

Breve descripción de Pisco:

* localización;
* principales actividades económicas;
* infraestructura estratégica;
* rol dentro del sistema territorial nacional.

Se recomienda incluir un mapa de ubicación.

---

# 3. Fase I. Análisis de la Situación Actual

## 3.1 Problema público

Presentar:

* formulación del problema;
* población afectada;
* localización;
* causas directas;
* causas estructurales;
* consecuencias;
* tendencia.

Incluir la matriz trabajada durante el taller.

---

## 3.2 Potencialidades

Presentar la matriz de potencialidades.

Explicar por qué dichas capacidades representan oportunidades para el desarrollo territorial.

---

## 3.3 Variables estratégicas

Identificar y justificar las variables seleccionadas.

Para cada variable explicar:

* qué representa;
* por qué es estratégica;
* cómo influye en el sistema territorial.

---

# 4. Fase II. Análisis Prospectivo

## 4.1 Tendencias

Seleccionar las tendencias más relevantes.

Para cada una indicar:

* descripción;
* impacto esperado;
* relación con las variables estratégicas.

---

## 4.2 Riesgos y oportunidades

Presentar:

* matriz de riesgos;
* matriz de oportunidades;
* mapa de relaciones (Gephi).

Explicar cuáles representan los principales desafíos para Pisco.

---

## 4.3 Construcción de escenarios

Desarrollar el procedimiento seguido:

### Paso 1

Agrupación temática.

### Paso 2

Análisis de impacto sobre las variables estratégicas.

### Paso 3

Narrativa del escenario.

Presentar al menos tres escenarios:

* escenario tendencial;
* escenario crítico;
* escenario óptimo.

---

# 5. Discusión

Responder preguntas como:

* ¿Qué variable estratégica resulta más determinante?
* ¿Qué riesgo representa la mayor amenaza?
* ¿Qué oportunidad tiene mayor capacidad transformadora?
* ¿Qué instrumentos públicos podrían intervenir sobre dichas variables?

---

# 6. Conclusiones

Presentar entre cuatro y seis conclusiones.

Las conclusiones deben centrarse en:

* funcionamiento del sistema territorial;
* principales variables estratégicas;
* implicancias para el ordenamiento territorial;
* aportes del enfoque prospectivo.

# Formato

* Extensión: 15–20 páginas (sin anexos).
* Letra: Calibri o Arial 11.
* Interlineado: 1.5.
* Márgenes: 2.5 cm.
* Figuras y tablas numeradas.
* Todas las fuentes correctamente citadas.

# Producto esperado

Más que un informe académico, el producto final debe asemejarse a un **informe técnico de diagnóstico y prospectiva territorial**, capaz de sustentar decisiones de planificación, inversión y gestión pública.

El objetivo no es únicamente describir el territorio, sino demostrar cómo el análisis de problemas públicos, potencialidades, variables estratégicas y escenarios permite orientar intervenciones para el desarrollo territorial sostenible.
